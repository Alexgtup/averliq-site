ЗАДАЧА

Аудит должен быть доказуемым.

Вместо оценки «потому что так решила нейросеть» сервис привязывает каждую проблему к конкретному HTTP или HTML-сигналу и показывает, что именно исправить. Его можно использовать как бесплатный инструмент, лид-магнит и рабочую проверку перед SEO-доработками.

SEO signals

02

robots.txt, sitemap discovery, URL count, ограниченная выборка внутренних страниц.

03

Links & media

Internal/external links, выборочная проверка HTTP-статусов, broken links и изображения без alt.

04

Security baseline

HTTPS, CSP, HSTS, Referrer-Policy и X-Content-Type-Options как отдельный технический слой.

БЕЗОПАСНОСТЬ

Crawler не должен стать SSRF-прокси.

Публичный аудит означает исходящие HTTP-запросы по пользовательскому URL. Поэтому безопасность встроена в сетевой слой: разрешены только HTTP(S), DNS проверяется до каждого запроса, приватные и служебные диапазоны блокируются, запрос закрепляется за проверенным IP, а каждый redirect проходит проверку заново.

DNS

Public IP only

localhost, private, link-local и service ranges не проходят до HTTP-запроса.

TLS

Host + SNI

Запрос идёт на проверенный IP, сохраняя исходный Host и TLS servername.

LIMITS

Bounded crawl

Timeout, response-size, redirect-count, crawl sample и concurrency ограничены.

ABUSE

Rate limiting

Публичный API ограничивает количество аудитов на IP.

ПРОВЕРКА

Не только unit tests. Реальный сайт.

Render-сборка запускает тесты сетевого слоя, URL parser, HTML analyzer и score. Отдельный integration-test выполняет настоящий аудит production-портфолио через тот же безопасный crawler.
