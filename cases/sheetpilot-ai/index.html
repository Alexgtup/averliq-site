SheetPilot AI.

ИИ-ассистент для редактирования и обработки Excel-файлов. Пользователь загружает таблицу, пишет задачу обычным языком, видит точный предпросмотр изменений и получает новый файл без перезаписи исходника.

Рабочий MVPСмотреть интерфейс ↓
PythonFastAPIopenpyxlGroq / GPT-OSSStructured JSONXLSX
01 / ЗАДАЧА

Не искать нужную ячейку. Описать результат.

Идея проекта — убрать ручную рутину из типовых операций в Excel. Ассистент не отдаёт нейросети право напрямую менять файл: модель формирует ограниченный план действий, код проверяет его, показывает diff и только затем создаёт новую версию таблицы.

01

Команды обычным языком

Например: «увеличь цены на 7%», «заполни пустые значения» или «очисти пробелы».

02

Предпросмотр до записи

Пользователь видит, какие значения будут изменены, до создания результата.

03

Исходник остаётся нетронутым

Результат сохраняется отдельным XLSX-файлом, поэтому операция обратима.

04

Режим без платного API

Базовые команды поддерживаются локальным rule-based fallback, AI-провайдер подключается отдельно.

02 / КАК РАБОТАЕТ

ИИ планирует. Код исполняет.

Такой контур снижает риск случайных действий модели и позволяет контролировать операции над таблицей.

Загрузка

Сервис принимает XLSX/XLSM и читает структуру книги.

Команда

Запрос преобразуется в JSON-план из разрешённого набора операций.

Preview

До применения показываются изменяемые ячейки и значения «было → станет».

Экспорт

После подтверждения создаётся новая версия Excel-файла.

03 / MVP

Что уже работает.

В текущем прототипе проверен полный путь от загрузки файла до экспорта результата. Публичную демо-версию добавлю после отдельного развёртывания сервиса.

Редактирование значений

Реализовано: изменение конкретных ячеек и диапазонов, массовая замена текста, числовые изменения и проценты.

Очистка таблицы

Реализовано: заполнение пустых значений, очистка строк и базовые операции над строками по условию.

Безопасный AI-контур

Реализовано: структурированный JSON-план, whitelist операций, проверка перед применением и защита от прямого исполнения текста из ячеек.

Проверенный сценарий

Интеграционный тест: команда «увеличь цену на 7%» прошла путь upload → preview → новый XLSX.

04 / ИНТЕРФЕЙС

Один продукт. Несколько сценариев.

Здесь используется прямой снимок работающего сервиса: загрузка Excel, команда обычным языком и подготовка плана изменений.

05 / СТЕК

Fullstack-проект, а не чат поверх API.

FastAPI отвечает за загрузку и API, openpyxl — за работу с книгой Excel, LLM используется как планировщик действий, а исполняет изменения контролируемый backend. Для AI предусмотрен бесплатный провайдер и локальный fallback для базовых команд.

BACKEND

FastAPI

REST API, загрузка файлов, сессии обработки и выдача результата.

EXCEL

openpyxl

Чтение, анализ, изменение значений и сохранение новой книги.

AI

Groq / GPT-OSS

Преобразование естественного языка в структурированный план действий.

SAFETY

Constrained execution

Модель не выполняет произвольный код и не получает прямой доступ к записи файла.

Публичное демо — следующий шаг.
