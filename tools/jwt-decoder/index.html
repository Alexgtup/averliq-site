Decoder ≠ проверка подписи.

Payload JWT обычно просто Base64URL-кодирован и читается без секрета. Доверять claims можно только после верификации подписи на backend по ожидаемому алгоритму, ключу, issuer, audience и сроку действия.

Безопасно ли вставлять access token?

Инструмент не отправляет значение на backend, но секретные production-токены всё равно лучше не копировать без необходимости.

Почему декодированный JWT может быть поддельным?

Потому что декодирование показывает содержимое, но не доказывает целостность и происхождение токена.
