FAQ

What is needed to start.

Do you need passwords immediately?

No. A URL and a clear symptom are enough for the initial assessment. Access is requested only where it is required to verify a data source or apply a fix.

Can you set up only Metrica and goals?

Yes. If technical SEO is not needed now, the scope can stay focused on tracking, goals and paid-traffic attribution.

Can you fix issues inside an existing WordPress site?

Yes, when the project can be changed safely. A full rebuild is not required for most tracking and technical SEO fixes.

Do you guarantee rankings?

No. The technical work itself can be verified: correct signals, fixed errors, working goals and a clear post-change check. Rankings depend on more than technical SEO.
